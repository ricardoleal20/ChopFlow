# Menu bar glyphs (source)

The three tray-menu glyphs are Google **Material Symbols** (Rounded, 24px):

- `play_arrow.svg` — Start broker / Start gateway
- `stop.svg` — Stop broker / Stop gateway
- `power_settings_new.svg` — Quit ChopFlow

Copyright Google LLC, licensed under Apache-2.0 (same license as ChopFlow).
Source: https://github.com/google/material-design-icons (symbols/web/<name>).

`scripts/gen-app-icons.py` renders them white-on-transparent (16px) for the
macOS `IconMenuItem`s.
